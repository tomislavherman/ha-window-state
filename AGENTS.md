# Repository instructions

## Skills

For preparing or publishing a version, read and follow
[release-version](.agents/skills/release-version/SKILL.md). It covers version
selection, version files, validation, pushing, and GitHub releases for HACS.

## CodeGraph

If a `.codegraph/` directory exists at the repository root, use CodeGraph before
searching or reading code to locate or understand it. Use the `codegraph_explore`
MCP tool, or `codegraph explore "<symbols or question>"`. If the directory does
not exist, skip CodeGraph; do not create an index automatically.
